## 502/503 业务重试强制新连接

在「OpenAI 上游 502/503 自动重试」下增加「502/503 重试时强制新建 WS 连接」，默认关闭。

同时满足以下条件才生效：

1. 开启 502/503 自动重试及本选项。
2. 开启强制上游 WS，且当次请求分组命中强制 WS 的范围。
3. 当次请求已经按原有错误规则、安全输出判断及预算决定进入下一次业务重试。

生效时，本次重试跳过主连接、备用连接和预热连接的复用，通过原连接池新建连接。仍使用原账号选择结果、代理、认证与请求内容，并遵守原连接池容量和建连限速。账号重试次数、总预算、延迟、同账号重试及换账号逻辑、计费逻辑不因这个选项而改变。已有独立的处理错误新连接重试保持独立预算。

首次请求不受此选项影响。不增加任何新的可重试错误类型；已输出实际内容、客户端取消、重试预算耗尽等限制仍沿用原逻辑。新连接正常产生握手耗时，不保证比连接复用更快，也不保证上游缓存命中率。

关闭本选项后恢复原有连接选择。关闭强制 WS 或 502/503 自动重试并保存时，本选项自动清除；再次打开前置开关不会自动重新开启它。HTTP、BPS 和未命中强制 WS 分组的请求不启用这项新行为。

配置键：`openai_upstream_5xx_retry_force_new_connection`。使用既有 settings 存储，不新增表。读取、保存、返回、审计及缓存更新已接通。
