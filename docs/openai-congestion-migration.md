# OpenAI OAuth 拥堵换号

账号管理顶部点击“拥堵换号”打开设置窗口。仅点击按钮不会启用或停用，修改后点击“保存设置”才生效。支持恢复推荐参数和取消。设置保存到数据库，重启保留；旧版本只保存 enabled 的客户端不会覆盖已配置的阈值。

## 关闭时

继续走原有选号、粘性、排队、重试、HTTP/WS 转发和计费代码。不建立请求迁移状态，不读取 Redis 迁移标记，不运行新增拥堵等待。配置读取有进程内缓存；当前实例保存后立即更新缓存，其他实例最多约 5 秒刷新。

已经换号成功的会话仍保留普通粘性绑定，关闭不会强行切回旧账号。已经发出的请求继续处理。

## 推荐参数与配置作用

所有以下参数都可在窗口调整；每种触发条件可独立开关，开启的条件之间为“任一满足”。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| 观察窗口 / 每账号样本上限 | 60 秒 / 256 | 分别限制首响应和结束结果的短期记录；判断按相同请求模型筛选 |
| 持续慢响应 | 开启 | 至少 5 个首响应样本，至少 50% 等待超过或达到 15 秒 |
| 慢响应最低占用 | 0% | 默认独立于并发上限；40/1000 也会判断，设 80% 可增加占用条件 |
| 首响应等待堆积 | 开启 | 至少 5 条且占该模型在途请求 20% 的请求，等待首响应达到 20 秒 |
| 连续上游错误 | 开启 | 至少 5 个结束样本，至少 3 个且占 30% 的异常；429、5xx、网络错误分别可选 |
| 并发占用过高 | 开启 | 占用达到 100%，有候选才等待 2 秒并重新检查；等待可设 0 秒 |
| 目标占用上限 / 最少空位 | 50% / 1 | 必须符合这两个条件并且没有已启用规则判定的异常 |
| 要求目标明显更快 | 开启 | 慢响应/等待堆积换号时比较同模型平均首响应，目标至少 3 个样本且快 30%；等待堆积时比较基准至少为等待阈值 |
| 允许目标样本不足 | 关闭 | 开启可尝试健康、有空位但缺乏速度样本的目标，不能保证更快 |
| 换号保护时间 | 120 秒 | 成功后在此时间内不再次拥堵换号；0 关闭保护，仍保留粘性绑定 |
| 进行中换号协调时间 | 600 秒 | 同会话并发共享目标的 Redis 标记最长保留时间，不是请求超时 |
| 新会话避开异常账号 | 开启 | 有可用健康候选才过滤确认异常的账号；其余排序仍由原调度器决定 |

首响应指上游开始返回数据，包含响应创建通知，不是整条回答完成，也不是用户可见文字首 token。首响应一到即记录，长回答无需结束就可形成样本。已经收到首响应的长输出不会被当作首响应等待堆积。客户端取消不计入上游故障。没有额外探测请求。

## 换号与安全边界

正常会话优先原账号。目标须是同请求允许使用的 OpenAI OAuth 账号；分组、模型、额度、利润准入、传输能力、优先级与原子并发槽位仍由原调度器检查。只有一个账号、没有合适目标或全部拥堵时，回到原有有上限排队。

同会话并发通过 Redis 原子标记共享目标，目标完整转发成功后才更新绑定；失败不提交。旧请求不能覆盖或删除新绑定。保护期结束不会自动回切。样本不足时默认先积累正常流量；可以明确开启尝试无样本目标。

只在请求发出前选号，不中断在途请求、不增加上游超时或额外重发、不暂停或冷却原账号。已有重试重新选号时依然受原有次数和已输出内容限制。请求内容、工具、缓存标识及计费保持原处理方式。

适用于 HTTP 入站的 Responses、Chat Completions、Messages，上游可为 HTTP、强制 WS 或 BPS。原生 WS 入站、previous_response_id 或 item_reference 续接、压缩、图片及 Guardian 父会话绑定不主动换号。

## 运行与验证

健康样本只在进程内保存，重启重新积累；多实例各自观察本实例流量，会话协调由 Redis 共享。配置范围校验限制内存和等待上限；Redis 或设置读取失败回退原路径。没有数据库结构迁移。

日志 openai_congestion_migration_started 表示已选中目标，openai_congestion_migrated 表示成功提交绑定，均不是新增使用记录或计费项。

测试包括低占用慢响应、首响应提前记样本、不同模型隔离、各触发条件和比例、目标速度比较、未知目标、样本上限、保护/协调时间、配置保存与关闭回退、并发槽位释放和同会话并发绑定；浏览器验证窗口保存、取消、校验和小屏显示。
