# Qerkai 升级至 upstream 0.2.20

## 版本与合并

- Qerkai 起点：`790500a8a99fc861da587195703065ae8ed403c4`（0.2.16）。
- 上游：`6b4b37db43443b5e88e424fe3c69602cc3810dfb`。与 `v0.2.20` 标签的业务代码一致，仅追加官方 VERSION 修正到 0.2.20。
- 保留双方历史的三方合并；人工处理调度入口、账号事务与暂停条件、响应首帧、设置和服务退出流程的冲突，重新生成 Ent / Wire。

## 保留的二开

保留强制 WS 及分组范围、WS 连接池优化、CPA 网络首帧、502/503 规则和计数、强制新连接重试、State 采集注入、降智检测及账号代理、暂停恢复与分组切换、RPM、下游模型显示、使用日志字段、代理快捷导入、可配置拥堵换号和会话绑定。

拥堵开关关闭仍直接进入上游选号器；开启仅作用于原有允许换号的请求。上游图片尺寸选号封装正常保留。账号手动分组修改继续在事务内锁定账号后读取原分组；State 有效期、手动暂停所有权和凭据变化保护保留。余额预留仍默认关闭。

## 移除 BPS

按管理员本次要求完整移除 BPS 开关、设置、HTTP/WS 转发执行器、模型目录扩展、账号测试选项及对应专用模块。降智请求恢复使用正常账号测试路径，继续使用账号代理及已配置的 State 注入。

数据库中的旧 BPS 设置不再读取或写入，不能开启路由，也不会限制强制 WS 保存。历史用量保留，端点列显示实际已记录的路径；模型检测仍排除历史已移除端点的日志，避免将旧路线样本用于当前账号恢复。

## 上游新增行为

- 请求体缓冲总预算默认 1 GiB，`gateway.request_body_memory_budget_bytes=0` 可关闭。该值是整个实例预算，超额是本地 503，不属于 OpenAI 502/503 业务重试。
- 请求体读取、下游写入停滞超时默认各 120 秒，并非整个回答只能持续 120 秒。客户端断开后收集尾部用量有界限。
- 合入 scoped 管理员密钥、MCP OAuth、模型目录、图片按张计费选项及官方计费修正。既有管理员认证保留；受限新密钥未登记的自定义管理接口默认拒绝，全权限和原管理员认证继续可用。MCP 未配置公开 URL 时不启用。
- OAuth 的 GPT-5.5 下线规则按官方版本执行；API Key 和显式映射到有效替代模型的规则沿用上游。
- 既有 303 个 SQL 迁移保留原内容，新增 246–249 四个官方迁移（按完整文件名识别）。按张计费默认关闭；Gemini / Antigravity 既有分组的生图开关由官方迁移开启。

## 验证

- 前端全量 3,224 项测试；合并丢失的中英文“更多筛选”翻译已补回，相关测试复测通过。类型检查、生产构建和 ESLint 通过。
- 后端完整 unit / integration 回归；修正新增 SQL mock 的自定义列和 MCP 测试默认设置，并恢复模型可用性诊断为上游逻辑。上述失败项定向复测通过。
- BPS 旧设置不阻止强制 WS 保存，设置响应不再包含 BPS 字段；账号测试、降智账号代理与 State 路径定向回归通过。
- 独立 PostgreSQL / Redis 测试环境验证空库安装及当前 303 个迁移升级到 307 个迁移；账号、余额、密钥、历史用量、设置和调度暂停触发器保持正确。
